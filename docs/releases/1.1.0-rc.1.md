# AEC Codex 1.1.0-rc.1

This is the first public release candidate of AEC Codex. It is intended for
cross-machine testing with disposable Autodesk documents.

## Included

- AutoCAD 2024 and Revit 2024 current-user connectors.
- Local Codex plugin and authenticated MCP connector gateway.
- Pinned Revit and AutoCAD structured providers with checksummed builds.
- Audited Revit runtime dependency lock with zero known npm vulnerabilities at
  release build time.
- Previewed writes and transaction-safe Autodesk fallback execution.
- Install, repair, uninstall, and verified bootstrap workflows.

## Validation status

- AutoCAD 2024 provider discovery: 47 allowed tools.
- AutoCAD 2024 rollback: test entity removed, entity count restored, connector
  remained responsive, and no exception dialog appeared.
- Revit 2024 final live acceptance remains pending.

## Known issues

- AutoCAD rollback can leave the drawing marked modified after all transaction
  entities have been removed.
- AutoCAD command history can show one transient `_UNDO` argument prompt.
- Autodesk versions other than 2024 are not supported.

## Install

Download the ZIP and its `.sha256` file, verify the checksum, close Revit and
AutoCAD, extract the archive, and run:

```powershell
& .\installer\Install-AecCodex.ps1 -SkipBuild
```

Restart Codex and the Autodesk applications, then start a new Codex task.
The first AutoCAD provider installation requires internet access for its
Python dependencies.
