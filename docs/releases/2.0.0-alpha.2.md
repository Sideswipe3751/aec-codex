# BIM Bridge 2.0.0-alpha.2

This prerelease fixes cross-version Host installation when a machine has a mix
of compatible and incompatible Autodesk runtime variants.

## Certified connectors

- AutoCAD 2024 (`net48`), 2025 (`net8.0-windows`), 2026
  (`net10.0-windows`), and 2027 (`net10.0-windows`).
- Revit 2024 (`net48`), 2025 (`net8.0-windows`), 2026
  (`net10.0-windows`), and 2027 (`net10.0-windows`).

## Installation behavior

The installer deploys all detected compatible certified connectors. Installed
Autodesk versions whose exact runtime is not certified are reported in
`skippedProducts` and do not block or roll back compatible versions. For
example, Revit 2026 through 2026.4 (`net8.0-windows`) is skipped while Revit
2024, 2025, 2027, or compatible AutoCAD connectors continue to install.

Stale BIM Bridge manifests for skipped Revit versions are removed within the
same recoverable installation transaction so Autodesk cannot load an
incompatible connector.

## Distribution

The Windows x64 Host archive is immutable and pinned by SHA-256 in the signed
Codex release manifest. Install or refresh the lightweight Codex plugin through
the Repo Marketplace, restart Codex, and let its read-only preflight present
the exact compatible and skipped products before granting Host consent.

This is an alpha prerelease. Keep backups and use disposable Autodesk documents
for write testing.
