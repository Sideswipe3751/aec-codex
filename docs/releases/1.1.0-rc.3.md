# AEC Codex 1.1.0-rc.3

This release candidate is the first public-directory-ready build. An ordinary
Codex user can install the Skills-only listing and, after explicit approval in
the first task, let Codex install the native Windows host from this immutable
release.

## Highlights

- No system Python installation is required for ordinary users.
- The host carries a private, pinned CPython 3.12.10 runtime.
- The installer registers the external `aec-codex-local` MCP and restores the
  previous Codex configuration if installation fails.
- AutoCAD provider dependencies are resolved only on the trusted release
  machine and locked to exact versions.
- A separate Skills-only ZIP is available for Plugins Directory review; it
  contains no native connector binaries or bundled MCP configuration.

## Compatibility

- Windows x64.
- AutoCAD 2024 and Revit 2024 only.
- Codex desktop or CLI with plugin and external MCP support.

Autodesk 2025, 2026, and 2027 remain unsupported in this release.

## Validation

- Windows PowerShell 5.1 installer contract tests passed.
- Ten MCP routing, safety, and launcher tests passed.
- The full .NET solution built and tested in Release configuration.
- The AutoCAD and Revit provider bundles initialized with 47 and 25 allowed
  tools respectively.
- A clean extraction of the host payload initialized the MCP server using only
  its bundled Python runtime.
- The public submission bundle passed its native-binary, key-file, local-MCP,
  and remote-pipe execution guards.

## Known issues

- Revit 2024 final live acceptance remains pending.
- AutoCAD rollback can leave a drawing marked modified even after all test
  entities have been removed.
- AutoCAD command history can show one transient `_UNDO` argument prompt.
