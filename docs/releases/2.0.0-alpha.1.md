# BIM Bridge 2.0.0-alpha.1

This prerelease is the first BIM Bridge Host package for the shared,
matrix-driven Autodesk architecture. It is intended for controlled testing on
disposable models and drawings.

## Certified connectors

- AutoCAD 2024 (`net48`), 2025 (`net8.0-windows`), 2026
  (`net10.0-windows`), and 2027 (`net10.0-windows`).
- Revit 2024 (`net48`), 2025 (`net8.0-windows`), 2026
  (`net10.0-windows`), and 2027 (`net10.0-windows`).

The AutoCAD 2024-2027 acceptance runs verified exact routing, selection, read,
write, committed readback, intentional rollback, rollback readback, cleanup,
descriptor cleanup, and clean shutdown.

## Distribution

The Windows x64 Host archive is immutable and pinned by SHA-256 in the signed
Codex release manifest. Install the lightweight Codex plugin through the Repo
Marketplace, restart Codex, and let its read-only preflight present the exact
Host plan before granting separate installation consent.

This is an alpha prerelease. Keep backups and use disposable Autodesk documents
for write testing.
