# BIM Bridge 2.0.0-alpha.4

This prerelease makes Revit and AutoCAD connector discovery diagnosis explicit
without exposing connector credentials.

## Descriptor evidence

The read-only Host status now reports:

- the BIM Bridge 2.x descriptor directory at
  `%APPDATA%\BIM Bridge\instances`;
- descriptor filenames, sizes, and timestamps from that directory;
- the separate `%APPDATA%\AEC Codex\instances` legacy compatibility fallback;
- the existence and timestamp of
  `%APPDATA%\BIM Bridge\connector-errors.log`.

The probe does not read or return descriptor bearer tokens. Authoritative JSON
validation, health checks, and target selection remain owned by the neutral BIM
Bridge Runtime.

## Revit 2024 diagnostic clarification

A Revit journal reference-version warning followed by `API_SUCCESS` is not, by
itself, evidence that BIM Bridge failed to start. `ConnectorServer.Start()`
writes the initial descriptor synchronously before the external application's
startup succeeds. Diagnosis should therefore inspect the BIM Bridge 2.x
descriptor evidence and connector error log, not only the legacy AEC Codex
directory.

The alpha.3 fixes for custom Autodesk installation paths and generated Python
bytecode integrity remain included. The certified Autodesk connector matrix is
unchanged.
