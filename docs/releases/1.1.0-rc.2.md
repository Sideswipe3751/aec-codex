# AEC Codex 1.1.0-rc.2

This release candidate adds first-run installation through a version-pinned
Codex repository marketplace. Its exact host payload and SHA-256 are recorded
in `plugins/aec-codex/release-manifest.json`.

## Added

- Repository Marketplace metadata.
- Read-only setup and installation health states.
- Explicit consent boundary before native host changes.
- HostOnly install, repair, upgrade, and uninstall behavior.
- Pinned release bootstrap and installer contract tests.

## Compatibility

- AutoCAD 2024 and Revit 2024 only.
- Windows x64.
- Python 3.11 or newer for this release candidate.

Autodesk 2025, 2026, and 2027 remain unsupported in this release.

## Validation

- Plugin and Skill schema validation passed.
- PowerShell 5.1 installer contract tests passed.
- PowerShell launcher preserved MCP STDIO JSON-RPC framing.
- AutoCAD and Revit providers initialized with 47 and 25 allowed structured
  tools respectively.
- Host payload content, sensitive-file filters, and source hashes passed.
- AutoCAD 2024 rollback acceptance from rc.1 remains valid; Revit 2024 final
  live acceptance is still pending.
