# BIM Bridge 2.0.0-alpha.3

This prerelease fixes Host installation for Autodesk products installed outside
the standard Program Files directory.

## Custom installation paths

The lightweight status probe and packaged Host installer now use one shared
discovery implementation. It checks a validated explicit product/version path
override when supplied, then Windows installer registry records, and finally
the standard Program Files locations derived from the Autodesk version matrix.

A discovered directory is accepted only when the expected Autodesk executable
and API assembly are present. Status and install state retain the exact
`installPath` and `detectionSource` evidence. A registered Revit 2024 install
such as `E:\Revit2024\Revit 2024` therefore receives the certified `net48`
connector without a directory junction or environment-variable workaround.

## Integrity status

Generated Python `__pycache__` directories and `.pyc` files are excluded from
the immutable release payload and installed-file integrity records. Normal
runtime bytecode generation no longer causes a false `needs_repair` result.

## Compatibility

The exact connector certification matrix is unchanged from alpha.2. Mixed
compatible and incompatible Autodesk runtime variants still install
independently, with incompatible variants reported in `skippedProducts`.

This is an alpha prerelease. Close Codex, Revit, and AutoCAD as instructed by
the installer and verify health in a new task after installation.
