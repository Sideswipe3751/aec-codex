# BIM Bridge support

BIM Bridge currently has live acceptance evidence for AutoCAD 2024 and Revit
2024, 2025, 2026, and 2027 on Windows x64. Release packaging remains frozen
while the runtime architecture and later AutoCAD version matrix are completed.

Before reporting a problem, start a BIM Bridge task and ask it to run the
read-only host status check. Do not post drawings, models, access tokens,
customer names, private paths, or other confidential project data publicly.

- Bugs and installation problems: <https://github.com/Sideswipe3751/bim-bridge/issues>
- Security vulnerabilities: <https://github.com/Sideswipe3751/bim-bridge/security/advisories/new>
- Documentation and source: <https://github.com/Sideswipe3751/bim-bridge>

Include the BIM Bridge version, Windows version, Autodesk product/version,
status JSON with sensitive paths removed, and exact reproduction steps.
