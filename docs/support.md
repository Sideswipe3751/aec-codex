# AEC Codex support

AEC Codex currently supports Windows x64 with AutoCAD 2024 and/or Revit 2024.
Other Autodesk versions are not supported by the rc.3 connector set.

Before reporting a problem, start an AEC Codex task and ask it to run the
read-only host status check. Do not post drawings, models, access tokens,
customer names, private paths, or other confidential project data publicly.

- Bugs and installation problems: <https://github.com/Sideswipe3751/aec-codex/issues>
- Security vulnerabilities: <https://github.com/Sideswipe3751/aec-codex/security/advisories/new>
- Documentation and source: <https://github.com/Sideswipe3751/aec-codex>

Include the AEC Codex version, Windows version, Autodesk product/version,
status JSON with sensitive paths removed, and exact reproduction steps.
